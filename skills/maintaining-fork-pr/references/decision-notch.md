# The `decision:` notch

Read this before you write a `decision:` notch or mark an item "decision needed" (step 2).

Write one only when all three hold:

1. No note in the branch or release chain answers the question. Quote the closest one.
2. The notch gives your recommendation and its evidence.
3. The choice needs authority you lack (money, an upstream commitment, removing what the maintainer asked for), not confidence.
